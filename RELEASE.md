# Alpha File Manager v0.3.1

- Added drag and drop within a pane, between panes, and to or from other apps. Items move on
  the same disk and copy across disks; hold Ctrl to copy or Shift to move. Dropping onto a
  folder puts the items inside it.
- Kept multi-selections intact when dragging, in both the list and icon views.
- Made split view fit the default window width again by moving the sort and view controls
  next to the address bar.

The Linux x86-64 archive includes the executable and a per-user launcher installer.
It requires GTK 3 and a compatible glibc. See the README for source builds.
