# Alpha File Manager v0.1.0

Primeira versão pública para Linux, com GTK 3 nativo.

- Abas, painel duplo, atalhos fixados e navegação por teclado e barra de endereço.
- Menu de contexto com operações de arquivos, miniaturas e ordenação por propriedades.
- Barra lateral recolhível, banner panorâmico personalizável, quatro perfis de cores e transparência opcional.
- Instalador de lançador por usuário e integração com o gerenciador padrão do Xfce.
- Código-fonte sob AGPL-3.0.

## Arquivos para publicação

- `alpha-file-manager-v0.1.0-linux-x86_64.tar.gz` — binário e instalador para distribuições compatíveis com o Kali Rolling.
- `alpha-file-manager-v0.1.0-linux-x86_64.tar.gz.sha256` — checksum do pacote.

Publique os arquivos do diretório `dist/` na release da tag `v0.1.0`. O GitHub disponibiliza
os arquivos-fonte da tag junto com o pacote.
