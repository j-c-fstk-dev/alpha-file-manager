# Alpha File Manager v0.2.0

- Added header menus, file and folder context actions, and new keyboard shortcuts.
- Added automatic English and Portuguese localization based on the system language.
- Added a persistent 60–100% opacity slider when transparency is enabled.
- Made English the primary README language and added a linked Brazilian Portuguese edition.

The Linux x86-64 archive includes the executable and a per-user launcher installer.
It requires GTK 3 and a compatible glibc. See the README for source builds.
